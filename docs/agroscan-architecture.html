How everything works — vision, pack, RAG, and Qwen

Bangladesh farmer app · local RTX 3060
Not embedding RAG — TF-IDF + pack-first routing
August 2026

Two farmer entries, one FastAPI server. A leaf photo goes through three vision levels, then a verified disease pack (Qwen only writes a short wrap). A typed question hits the pack first, then the knowledge base, and only leftover open questions go through TF-IDF retrieval into local Qwen2.5-3B-Instruct.

Three backbones
EfficientNet-B3, ResNet-50, DenseNet-121. Masked to L2 crop.

How the “best answer” is chosen

  1. Each disease model emits softmax, aligned onto the shared class list (older 38-class checkpoints do not dilute Bangladesh-only classes).
  2. Probabilities are masked to the L2 crop so a tomato photo cannot win as rice blast.
  3. Code comment is explicit: NEVER average — pick the single model with the highest confidence.
  4. Uncertain if confidence < 0.45; UI warns if < 0.80 (retake photo / call an officer).
  5. Class label looks like Rice___Blast → plant + condition + pack lookup via advice_for().
If leaf_type.pt is missing, crop is estimated by summing disease-class probabilities by plant. L1 missing means the gate is skipped (is_leaf = true).

After the class is known

Header always

Leaf % · crop · disease · confidence. Bangla or English.

Try Qwen wrap · generate_vision_feedback

Does not call retrieve(). Prompt = scan header + pack title, 5 steps, 4 treatments, 3 prevention lines. 3–6 short sentences. Max 180 new tokens, greedy.

Quality gate · _llm_text_is_bad

Reject if one word is ≥22% of the text, or 6 identical tokens in a row. Known 3B collapse mode.

Fallback

vision+llm if Qwen is clean · vision+pack if rejected or unloaded · bare vision + “call 16123” if no pack.

Pipeline B

Chat router — pack is the product, Qwen is overflow

agrovet/llm_chat.chat_reply
agrovet/knowledge.resolve_disease_query

1. resolve_disease_query(message)

Score pack/KB candidates. If one disease+crop is clear → format the full pack reply (symptoms, steps, chemicals, 16123). source: pack. Qwen is not called.

2. Ambiguous name → clarify

Same kb_key on several crops (e.g. blight). Return options; wait for confirm_class. source: clarify

3. chatbot_reply / structural KB

Greetings, emergency, government links, “how do I use AgroScan”, scan-context follow-ups. If the KB text is already specific, return it. source: kb / context / pack

4. Only then generate_reply — RAG + Qwen

Runs if the KB answer is generic (“I can help with plant-leaf…”). retrieve(k=6) → prompt → Qwen. Fail → KB fallback. source: llm
Why this order

Chemical doses are a legal/safety surface. The pack is DAE/PPW-backed text. The 3B model is instructed never to invent products. Routing enforces that: named diseases never reach generation.

What a pack answer contains

  • Crop + disease title (EN and BN fields)
  • Pathogen, season, severity, source, last verified
  • Cultural control and fertilizer (BARC FRG-style)
  • Chemical options: product, AI, dose/L, timing, interval, max sprays, PHI, BD brands
  • Registration: verified AP, or “confirm with dealer/PPW”
  • Organic options, safety, legal, when to call 16123

Prompt Qwen actually sees (open questions only)

### Instruction:
You are AgroScan… ONLY use the retrieved guides below. Never mix one crop/disease into another. If guides do not cover the question, say you are unsure and suggest calling 16123. Do not invent products, doses, or symptoms.
Matched disease record (authoritative): {title + summary}   ← if named match
Retrieved guides:
[1] … [6] section chunks   or “none. Say you are unsure.”
### Input:
{farmer message}
### Response:
Bangla system prompt is used when lang starts with bn. allow_keys pins retrieval to the matched class_name / kb_key so maize blight steps cannot leak into potato late blight. Prompt truncated at 2048 tokens; generation max 220, do_sample=False.

What a treatment chunk looks like

Rice — Rice blast example (pack, not model): Tricyclazole 75% WP at 0.6 g/L, spray at booting and 50% heading, max 2 sprays, PHI 21 days, brands Trooper/Beam/Blasticure. Rotate to Nativo 75 WG. Stop urea; add MoP. Neck blast cannot be cured once the panicle is infected. Pack notes: AP numbers often “confirm with dealer” — blast vs brown spot have opposite nitrogen advice; retrieval pinning exists so those two are not merged.
This is not neural RAG
No dense embeddings, no Qwen-as-retriever, no vector DB. “Diamond spots on rice” will rank blast if those words sit in the chunk. A paraphrase with no shared n-grams may miss. Legacy DISEASE_GUIDES are indexed alongside the pack when the pack exists.

Qwen’s job in RAG

Generation only. It rewrites the retrieved sections into a farmer reply. It does not search. If snippets are empty, the prompt orders it to say it is unsure.

CPU vs GPU

Retrieval is CPU sklearn and always on. Qwen needs CUDA in auto mode (AGROSCAN_LLM_ENABLED=auto). Docker image is CPU PyTorch — LLM likely stays off there.

Rebuild

python -m agrovet.rag_build writes rag_disease_docs.json. clear_index_cache() drops the in-memory TF-IDF matrix.

Trust this
Pack JSON + vision class → farmer treatment. Routing, allow_keys, and the “only use retrieved guides” prompt exist to keep doses inside that pack.
Do not over-claim
There is no RAG eval set. The 1.5B LoRA is unused at serve. Docker/CPU likely never loads Qwen. GGUF export is still absent.
If you raise quality next
Train/attach agroscan-3b or serve 1.5B on a 1.5B base. Add a 20-query retrieval check that blast and brown-spot nitrogen advice never swap.
